# my-human-design-forecast

Monthly business forecasts, one folder per month (`month-year`, lowercase). The root `index.html` lists them, newest on top.

| Month | Folder | Moved from |
|---|---|---|
| July 2026 | `july-2026/` | `sunnysink/july-forecast-2026` |
| June 2026 | `june-2026/` | `sunnysink/june2026forecast` |

To add a month: put the page at `<month>-<year>/index.html` and copy a block in the root `index.html`.
